# Tasks

Any `- [ ]` checkbox is a task. Tick one in the preview and WebMD records the
day it was finished.

- [x] Read the welcome note ✅ 2026-09-14
- [ ] Tick this box in the preview to see the date appear
- [ ] Try the shorthand: type `due:friday :p2:` at the end of this line
- [ ] Book the soil delivery ⏫ 📅 2026-09-18 who:me #garden
- [ ] Ask Ada about spare seed trays who:ada #garden

## Shorthand

On a task line, `due:tomorrow`, `due:+2w`, or `due:10-01` becomes a date, and
`:p1:` to `:p5:` becomes a priority, as soon as the cursor leaves the line.
The file keeps the plain Obsidian Tasks emoji, so it stays readable anywhere.
An open task with no `who:` gets `who:me`, and one with no due date gets a
date a week out.

## The Tasks view

Open it from the checklist in the rail, or with `Cmd/Ctrl+Shift+T`. It collects
every open task in the workspace. The Board ranks them into Now, Soon, Later,
and Shelf; Sections files them by tag or heading. Click a `#garden` or
`who:ada` chip to filter.
