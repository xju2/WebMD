# Daily notes

A daily note is named after its date, like [[2026-09-14]], and lives in the
daily-note folder: `/daily` in this sandbox.

- Open today's note from the rail, or with `Cmd/Ctrl+Shift+D`. WebMD creates
  it from `daily/template.md` if it does not exist yet.
- The arrows in a daily note's toolbar step to the previous or next daily note.
- `/today`, `/yesterday`, and `/tomorrow` insert a link to that day's note.

The template can use `{{date}}`, `{{title}}`, `{{weekday}}`, and `{{quote}}`.
A quote needs an AI provider; without one the line stays empty.

In the Tasks view, tasks from daily notes group under the `##` heading they
sit beneath, so a week of work on one project reads as one pile.
